# Prompt-only 情报搜索包

这是一个**纯 Prompt 包**，不依赖插件系统。
把 `PROMPT.md` 发给 Agent，它会先问清目的、要搜什么、要什么输出，确认后再搜。

## 文件

- `PROMPT.md`：通用 Prompt，包含提问流程、角色、规则、执行步骤、输出结构。
- `config.template.yaml`：**仅作为 schema 参考/高级预填**；普通使用不需要编辑。

## 用法

1. 把 `PROMPT.md` 发给 Agent。
2. Agent 会按 4 组问题逐轮问（共 18 题，必答 9 题 + 条件必答）：
   - **A 目的**：这次搜索支持你做什么决定
   - **B 搜什么**：对象 / 视角 / 关键词 / 时间范围 / 区域 / 不看什么
   - **C 来源**：只要公开，还是公开 + 需要登录（需要时再问具体页面和登录方式）
   - **D 输出**：形态 / 要件 / 篇幅 / 受众 / 节奏
   - **E 交付**：文件放哪（只在要写文件时出现）
3. 回答后，Agent 给你一张"配置确认卡"。
4. 确认后开始搜索，按你要的形态给结果。

**只有第 1、2、3 题需要动脑**，其余多是一键默认。

## 高级用法

- 如果已经有 `config.yaml`，直接告诉 Agent 路径；它会跳过已填项。
- 想固定默认值，可以先把 `config.template.yaml` 填好，作为"预填配置"发给 Agent。
- 目的、视角、关键词、时间范围、区域、来源、输出、节奏都是配置项，不写死。

## 说明

- 浏览器、登录态、shell 由宿主 Agent 提供；Prompt 不内置浏览器。没有就只能做公开来源。
- `output.mode: ["chat"]` 时只在对话里给结果，不写文件。
- 要写文档/表格时才会问篇幅和目录。
- 默认只新建文件；**并进你已有文档**只会在真正写文件时问一次，且先备份、只追加、不删不改原文。
- 需要登录的来源：先打开浏览器让你登录，**同时**并行搜公开来源，不会让你干等。
- 抓取有节奏限制：同域请求间隔 ≥2 秒、429 退避，宁可换来源也不硬爬。
- 抓取有上限（每关键词 top 10、每条笔记评论 20 条、每角度 3 个页面），结果会附**抓取清单**（URL/类型/条数/状态）。
- 时间范围和节奏是两个独立配置：`task.lookback` 决定搜多久以前，`task.frequency` 决定要不要定期再跑。
